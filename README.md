# 开播铃

一个轻量的 Windows 桌面开播提醒工具，支持 B 站与斗鱼直播间。

## 功能

- 搜索主播、平台或房间号，并筛选全部关注、直播中或已暂停的主播。
- 统一圆角界面和细圆角滚动条；设置按提醒、运行、外观和关于分组，小窗口可滚动。
- 输入直播间号或网址添加主播，并自动获取主播头像。
- 严格区分斗鱼的真实直播与视频轮播；状态无法确认时不发送提醒。
- 斗鱼状态检查使用新请求绕过缓存，减少下播切换录播时的旧状态显示；平台自身的更新仍可能有延迟。
- 每位主播可单独暂停或恢复开播检查。
- 每位主播可单独设置提醒声音；未单独设置时使用默认声音。
- 多位主播同时开播时，提醒会堆叠显示，声音按顺序播放。
- 同一位 Windows 用户只能运行一个开播铃；重复启动会自动唤出已隐藏的窗口。
- 支持软件内提醒、Windows 提醒、开机自动启动和关闭后驻留右下角。
- 支持自定义软件头像、头像旁边的小字，以及任务栏与托盘显示的标签。
- 软件内提醒使用不激活窗口的方式显示；点击提醒时才会打开直播间。具体全屏游戏与手柄场景仍需实际验证。
- 点击提醒或“打开”可直接进入对应直播间。
- 双击主播可打开直播间；“···”菜单提供单独刷新、提醒音效和删除。
- 设置中可以预览软件小窗，测试提醒不会打开直播间或播放声音。
- 头像后台下载，不阻塞开播状态更新；头像按显示尺寸解码，避免每次检查重复加载大图。
- 最多同时检查三个直播间，同一房间不会同时发起多次重叠请求。
- 短暂断网或状态待确认后恢复，不会因此重复提醒同一场直播。
- 数据采用先写临时文件再替换的方式保存，并保留上一份 `.bak` 备份。
- 头像和声音在保存设置时才导入，取消选择不会覆盖原文件。

## 使用方法

1. 下载 Release 中的压缩包并解压到任意文件夹。
2. 双击 `开播铃.exe` 启动。
3. 点击“添加主播”，输入 B 站或斗鱼直播间号、或直播间网址。
4. 在“设置 → 外观”中更换软件头像、小字和任务栏标签。
5. 在“设置 → 提醒”中选择提醒方式、声音和停留时间，或查看小窗效果。
6. 在“设置 → 运行”中分别设置自启动、关闭后驻留后台和检查间隔。

程序数据会保存在启动文件旁的 `Data` 文件夹中。该文件夹包含个人关注列表和缓存，不会上传到 GitHub。

## 更新与运行要求

- 需要 64 位 Windows 和 .NET Framework 4.8。
- 更新前先从右下角托盘退出旧版，再替换 `开播铃.exe` 和 `Assets`；保留完整的 `Data` 文件夹。
- 不需要 Node，也不需要浏览器窗口。发布包不包含 .NET 运行环境。
- 程序尚未进行数字签名；若启动被拦截，应核对下载来源，不建议整体关闭杀毒软件。
- 平台自身的数据更新可能有延迟；本软件不保证所有直播状态始终准确。

- .NET Framework 4.8
