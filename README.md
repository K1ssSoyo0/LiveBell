# 开播铃

一个轻量的 Windows 桌面开播提醒工具，支持 B 站与斗鱼直播间。

## 功能

- 输入直播间号或网址添加主播，并自动获取主播头像。
- 正确区分斗鱼的真实直播与视频轮播。
- 每位主播可单独暂停或恢复开播检查。
- 每位主播可单独设置提醒声音；未单独设置时使用默认声音。
- 多位主播同时开播时，提醒会堆叠显示，声音按顺序播放。
- 支持软件内提醒、Windows 提醒、开机自动启动和关闭后驻留右下角。
- 点击提醒或“打开”可直接进入对应直播间。

## 使用方法

1. 下载 Release 中的压缩包并解压到任意文件夹。
2. 双击 `开播铃.exe` 启动。
3. 点击“添加主播”，输入 B 站或斗鱼直播间号、或直播间网址。

程序数据会保存在启动文件旁的 `Data` 文件夹中。该文件夹包含个人关注列表和缓存，不会上传到 GitHub。

## 开发环境

- .NET Framework 4.8
- Windows WPF
