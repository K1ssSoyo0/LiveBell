开播铃使用说明

当前版本：v1.2.2 内存优化版

1. 解压后直接双击“开播铃.exe”。请不要单独移动 exe，Assets 文件夹需要和它保持在同一个文件夹。
2. 点“添加主播”，可直接粘贴 B 站或斗鱼直播间网址，也可输入房间号。
3. “设置”分为提醒、运行、外观和关于：可分别设置提醒方式与声音、开机自启动、后台驻留、检查间隔和个性化外观。小窗口可以滚动。
4. 点击任意提醒可直接进入对应主播的直播间。
5. 可在“设置 → 外观”中更换左上角头像、头像旁边的小字，以及 Windows 任务栏和右下角托盘显示的标签；头像也会同步到任务栏与托盘图标。取消设置不会覆盖原文件。
6. 同一位 Windows 用户只能运行一个开播铃；重复双击会自动唤出已隐藏的窗口。
7. 主播信息、已下载头像与设置保存在程序文件夹下的 Data 文件夹中；软件不需要 Node，但需要 64 位 Windows 和 .NET Framework 4.8 或更高版本。
8. 软件内提醒采用不激活窗口的方式显示；只有用鼠标点击提醒，才会打开对应直播间。具体游戏与手柄场景仍需实际验证。
9. 斗鱼只有在平台明确确认“真实直播且不是视频轮播”时才会提醒；遇到平台数据暂时不完整时会显示“状态待确认”，不会误报。
10. 自定义头像会复制到 Data\appearance 文件夹，更新程序时保留整个 Data 文件夹即可继续使用。
11. 斗鱼状态检查会尝试绕过平台缓存，减少下播转录播时的显示延迟；平台自身更新有延迟时，仍需要等待后续检查。
12. 主界面可切换全部关注、直播中和已暂停；双击主播可进入直播间。
13. 音效、单独刷新和删除位于每行的“···”菜单中；自动检查开关仍可直接操作。
14. 可在“设置 → 提醒”中查看软件小窗效果；测试提醒不会打开直播间或播放声音。
15. 更新前先在托盘右键选择“退出”，再替换开播铃.exe 和 Assets，保留完整的 Data 文件夹。
16. 数据保存时会保留上一份 .bak 备份；头像在后台下载，不会阻塞状态更新。
17. 软件尚未进行数字签名；若被拦截，请确认下载来源，不要为了运行它而整体关闭杀毒软件。
18. 默认开启低内存绘制，保留圆角和头像；若拖动或滚动不流畅，可在“设置 → 运行”关闭，保存后从托盘完全退出并重启软件。
19. 本机短测 3 位主播时，工作集约从 307 MB 降到 124–127 MB；不同电脑、DPI 和运行时间下的占用会变化，不保证固定数值。
