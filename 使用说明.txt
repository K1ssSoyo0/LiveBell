开播铃使用说明

1. 解压后直接双击“开播铃.exe”。请不要单独移动 exe，Assets 文件夹需要和它保持在同一个文件夹。
2. 点“添加主播”，可直接粘贴 B 站或斗鱼直播间网址，也可输入房间号。
3. 在“设置”中分别选择：开机自启动、关闭窗口后驻留右下角通知区域、软件内提醒或 Windows 提醒、自定义提示音、软件内提醒停留时间，以及个性化外观。
4. 点击任意提醒可直接进入对应主播的直播间。
5. 可在“个性化外观”中更换左上角头像、头像旁边的小字，以及 Windows 任务栏和右下角托盘显示的标签；头像也会同步到任务栏与托盘图标。
6. 同一位 Windows 用户只能运行一个开播铃；重复双击会自动唤出已隐藏的窗口。
7. 主播信息、已下载头像与设置保存在程序文件夹下的 Data 文件夹中；软件不需要 Node，但需要 64 位 Windows 和 .NET Framework 4.8 或更高版本。
8. 软件内提醒显示时不会抢占全屏游戏或手柄的操作焦点；只有用鼠标点击提醒，才会打开对应直播间。
9. 斗鱼只有在平台明确确认“真实直播且不是视频轮播”时才会提醒；遇到平台数据暂时不完整时会显示“状态待确认”，不会误报。
10. 自定义头像会复制到 Data\appearance 文件夹，更新程序时保留整个 Data 文件夹即可继续使用。
